## 一、這是什麼

申請大學、研究所或各種學程時，每間學校要繳的資料項目不同、截止日不同，最怕的就是「漏繳一份」或「同一份檔案放錯地方」。

這個工具幫你做四件事：

1. **盤點**：每個申請包要繳什麼，一項一項列清楚（必繳／選繳分開）。
2. **歸類**：把資料夾裡的檔案拖進來，系統依檔名自動建議歸到哪個項目。
3. **檢查**：缺件用紅燈標示，並算出完成度；內容重複的檔案會用 SHA-256 抓出來。
4. **匯出**：產生繳件清單（Markdown／CSV）與建議的資料夾結構，照著放檔案就好。
5. **手寫**：需要手寫的項目（例如自傳、學習計畫）可標記「需手寫」，並用內建稿紙產生器排版列印。
6. **雙語**：介面可切換繁體中文／English，繳件清單也能選語言匯出。

### 隱私與安全

- 全程在**你的瀏覽器**裡運算，**檔案不會上傳**到任何伺服器。
- 可**離線使用**：index.html 是單一檔案，不需要網路、不連任何外部網站。
- 為保護隱私，工具**不保存檔案內容**，只在本機瀏覽器保存檔名、大小、相對路徑與 SHA-256 雜湊值。
- 手寫稿紙裡打的文字也只存在你本機瀏覽器（不會上傳），且你可以隨時按「清空」刪掉。

## 二、怎麼開始

1. 找到 `index.html`，**雙擊**用瀏覽器打開（Chrome、Edge、Safari、Firefox 皆可）。
2. 想把工具放桌面書籤或隨身碟都可以，整個 `書審資料包產生器` 資料夾複製走就能用。
3. 第一次用，建議先按 **「載入示範」**，看看兩個申請包長什麼樣子，再按 **「清空全部資料」** 重新開始。

## 三、五個步驟做完備審

### 步驟 1：建立申請包

在「① 申請包與應繳項目」：

- 選範本（**常見七項** 或 **空白**），按「＋ 新增申請包」。
- 一間學校／一個系組就建一個申請包，例如「○○大學｜△△學系」。
- 填上校名、系組，備註可寫截止日或特殊規定。

### 步驟 2：設定應繳項目

每個申請包下方的項目列可以：

- **改名**：直接點輸入框修改，例如把「學習計畫／讀書計畫」改成「讀書計畫」。
- **設必繳／選繳**：勾選「必繳」，完成度只計算必繳項目。
- **標記需手寫**：勾選「需手寫」，該項目右邊會出現「稿紙」按鈕（用法見第五節）。
- **設定關鍵字**：右側「自動歸類關鍵字（逗號分隔）」，用來判斷檔案該歸到哪一項；例如自傳填「自傳, 自述」。
- **新增／刪除／上下移動**：用右側按鈕調整。
- 按「＋ 匯入預設範本項目」可一鍵補回常見七項（已存在的不會重複加）。

> 請**依照該校簡章**設定項目，不要多放也不要少放；簡章沒要求的東西不要硬塞進去。

### 步驟 3：加入檔案

在「② 檔案歸類」：

- 把**整個資料夾**或一批檔案**拖進虛線框**；或按「選擇檔案」「選擇整個資料夾」。
- 系統會依檔名關鍵字**自動建議**歸類到某一項。建議錯了沒關係，下一步可以改。
- 上方「自動判斷／優先歸入」可指定這一輪匯入的檔案優先算在哪個申請包。

### 步驟 4：手動調整歸類

每一列檔案右邊有兩個下拉選單：

- 左邊選**申請包**，右邊選**項目**。
- 不確定的先留「（未歸類）」，最後再處理。
- 按「重新自動歸類未歸類檔」可讓系統再猜一次。
- 「內容重複」標籤代表這份檔案的內容與另一個檔案完全相同（SHA-256 相同）。

### 步驟 5：看缺件、匯出清單

在「③ 缺件檢查」：

- 🟢 已備妥　🔴 缺件（必繳）　⚪ 選繳未附
- 上方統計列顯示必繳完成度、缺件數、內容重複組數。

在「④ 匯出繳件清單」：

- **下載 Markdown（.md）**：完整清單，可貼進筆記軟體。
- **下載 CSV**：Excel／Numbers 可直接開啟（已處理正體中文編碼）。
- **複製建議資料夾結構**：可直接貼給自己或貼給 AI 助手幫你搬檔案。
- 下方預覽區同步顯示清單內容，可手動選取複製。

## 四、切換語言（繁體中文／English）

1. 打開頁面後，看**右上角**有兩顆按鈕：`繁體中文` 與 `English`。
2. 按一下 `English`，整個介面（標題、按鈕、提示、清單欄位）**立刻**變成英文；按 `繁體中文` 就換回來。
3. 你的選擇會**自動記住**，下次打開還是同一種語言（想改隨時按右上角那兩顆）。

**匯出清單要換語言（可以和介面不同）**

4. 到「④ 匯出繳件清單」，找到**匯出語言**下拉選單，選 `繁體中文` 或 `English`。
5. 再按 **下載 Markdown** 或 **下載 CSV**，匯出的清單就是該語言（例如選 English，標題會是 `# Application Document Checklist`）。
6. 匯出語言的選擇同樣會**自動記住**。

> 用途：介面用中文方便自己操作，清單用英文方便交給英文推薦人或國外學校。

## 五、手寫稿紙（標記需手寫 → 產生格紙 → 列印）

**先標記**

1. 在「① 申請包與應繳項目」，找到要手寫的項目（例如「自傳」），把右邊的 **「需手寫」** 勾起來。
2. 勾完後該項目會出現 **「稿紙」** 按鈕；這個勾選會存檔，下次打開還在。

**再產生稿紙**

3. 按該項目的 **「稿紙」** 按鈕，會跳出「稿紙－（學校｜項目）」視窗。
4. 在左邊大框框**打字或貼上**你的內容（例如自傳全文），右邊會**即時**長出格子稿紙。
5. 上方會顯示 **字數／行數／頁數／字數上限**，字數超過上限會出現**紅字警告**（告訴你超出幾個字）；把上限調高或刪減內容，警告就會消失、改顯示「尚可再寫 N 字」。

**調整外觀（左側面板）**

6. **樣式**：`方格`（一格一字，最常用）、`橫線`、`空白` 三選一。
7. **每行字數**：20～24 字，依簡章規定調整（改完頁數會跟著重算）。
8. **行距**：1.0～1.5 倍，讓字不要擠在一起。
9. **字數上限**：填 0 表示不限制；填簡章規定的字數（例如自傳 1000 字）。
10. **字型**：可選 `標楷體／楷體（建議）`、`手寫體（行楷／手寫風）`、`圓體`、`黑體（對照用）`；選好後把 **「字型預覽」** 打勾，畫面上就會用該字型顯示（不勾則用一般系統字型，較省資源）。
11. 想重打，按 **「清空」**。

**列印**

12. 按 **「列印」**，會開啟瀏覽器列印視窗；列印範圍**只有稿紙**（按鈕、面板都會自動隱藏），一張 A4 一頁，直接印出來照格子寫即可。
13. 關閉視窗：按右上角 ✕ 或畫面外空白處；按鍵盤 `Esc` 也可以。

> 小提醒：稿紙是幫你「對齊格子」用的，印出來是空白格線＋你打的字。若簡章要求**全手寫**，建議把文字當作「字數與版面試算」，實際書寫照著格子寫。

## 六、建議的實體整理流程

工具只做規劃與檢查，**不會也不能**自動搬移你電腦裡的檔案（瀏覽器安全限制，工具也讀不到完整磁碟路徑）。建議這樣做：

1. 在本工具裡建好所有申請包與項目。
2. 匯出「建議資料夾結構」，照著在電腦上建資料夾，例如：

```
書審資料包/
├─ ○○大學｜△△學系/
│  ├─ 個人資料表（必繳）
│  ├─ 成績單（必繳）
│  ├─ 自傳（必繳）
│  ├─ 學習計畫（必繳）
│  ├─ 推薦函（必繳）
│  └─ 其他有利資料（選繳）
└─ □□大學｜◇◇學程/
   └─ ...
```

3. 把檔案放進對應資料夾（**複製**而非剪下，母本留著最保險）。
4. 再回到本工具，按「選擇整個資料夾」把整理好的資料夾拖進來核對一次，確認沒有紅燈。

## 七、設定保存與換裝置

- 申請包、項目、歸類結果會**自動存在這台裝置的瀏覽器**，下次打開自動接續。
- 換電腦或手機：在原本的裝置按 **「匯出設定 JSON」**，在新裝置按 **「匯入設定 JSON」**。
- 使用無痕模式、清除瀏覽器資料、或瀏覽器空間不足時，設定可能遺失 → 重要進度請定期匯出 JSON 備份。

## 八、常見問題

**Q：一定要連網路嗎？**
不用。index.html 沒有引用任何外部檔案，飛航模式也能用。

**Q：檔案會被上傳嗎？**
不會。所有運算都在瀏覽器本機完成，沒有後端伺服器。

**Q：為什麼有些檔案顯示「未計算雜湊」？**
單檔超過 200MB 會略過雜湊計算（避免卡住）；沒有讀取權限的檔案也可能失敗。不影響清單與歸類功能。

**Q：為什麼工具讀不到檔案的完整路徑（例如 /Users/xxx/Documents/…）？**
瀏覽器基於安全設計，只會提供檔名與相對路徑。這是保護你電腦的做法，不是工具的問題。

**Q：可以用手機嗎？**
可以，介面已針對手機調整。但手機上「選擇整個資料夾」支援度較差，建議在電腦上做主要整理。

**Q：同一份檔案要交給兩間學校可以嗎？**
可以，但請先確認各校簡章是否允許內容相同（部分學校要求版本不得雷同）。工具會在「內容重複提醒」中標出內容完全相同的檔案，方便你確認。

**Q：按了「清空全部資料」會刪掉我的檔案嗎？**
不會。只清除本工具在瀏覽器裡的紀錄，你電腦裡的檔案完全不受影響。（稿紙裡打的文字也會一併清掉，需要的話先複製走。）

**Q：稿紙的字型看起來不像手寫體？**
字型預覽用的是你電腦裡**現有**的字型，若沒安裝對應字型會自動退回系統預設中文字型（不會亂碼、不會空白）。稿紙只負責幫你對齊格子，字跡由你親筆寫。

**Q：切到 English 之後，我原本建的項目名稱會變英文嗎？**
不會。你**自己輸入**的校名、系組、項目名稱、備註都保持原樣；只有工具介面的固定文字與匯出清單的欄位標題會跟著換語言。

**Q：列印稿紙時印出了整頁網站畫面？**
請直接從稿紙視窗按 **「列印」** 按鈕（不要用瀏覽器選單的列印），這樣才會自動只印稿紙。
